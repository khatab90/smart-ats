# نشر نسخة الويب برابط ثابت

النتيجة: رابط ثابت مثل `https://smart-ats-khatab.netlify.app` يفتح التطبيق على الهاتف والحاسوب، بشهادة HTTPS.

## الكلفة

خطة Netlify المجانية تعطي 300 رصيد شهرياً:

- كل تحديث تنشره يستهلك 15 رصيداً، أي حوالي 20 تحديثاً في الشهر.
- كل 1 GB تحميل يستهلك 20 رصيداً. التطبيق أقل من 1 MB في أول فتح ثم يُحفظ في المتصفح، فهذا يكفي للاستخدام الشخصي بسهولة.
- إذا نفد الرصيد يتوقف الموقع حتى بداية الشهر التالي، ولا يُسحب منك أي مبلغ.

## النشر أول مرة (من الحاسوب)

1. أنشئ حساباً مجانياً في [netlify.com](https://app.netlify.com/signup) (بحساب Google أو GitHub أو البريد). **سجّل الدخول قبل الرفع**: الرفع بدون حساب يُحذف خلال ساعة.
2. افتح [app.netlify.com/drop](https://app.netlify.com/drop).
3. اسحب الملف `smart-ats-web.zip` وأفلته في المربع، كما هو بدون فك الضغط.
4. بعد ثوانٍ يظهر الرابط. لتغيير اسمه: من إعدادات المشروع (Project configuration) غيّر اسم المشروع، مثلاً `smart-ats-khatab`، فيصير الرابط `https://smart-ats-khatab.netlify.app`.

من الهاتف قد ينجح اختيار الملف عبر «browse to upload»، لكن الحاسوب أضمن.

## تحديث الموقع لاحقاً

افتح نفس المشروع في Netlify ← تبويب **Deploys** ← اسحب ملف `smart-ats-web.zip` الجديد إلى مربع السحب في أسفل الصفحة. الرابط يبقى نفسه.

من يفتح التطبيق أثناء التحديث لا يتعطل: إذا فتح شاشة من النسخة القديمة يحمّل التطبيق النسخة الجديدة تلقائياً.

## بناء الملف بنفسك (اختياري)

```bash
npm install
npm run build:web
```

ثم اسحب المجلد `dist` كاملاً إلى Netlify بدل الملف المضغوط. هذا البناء لا يضم ملفات source maps.

## خطوة في Supabase (مع مرحلة قاعدة البيانات)

حتى تفتح روابط البريد (تأكيد الحساب، استعادة كلمة المرور، الدعوات) الموقع الجديد:

Supabase ← Authentication ← URL Configuration:

- **Site URL**: رابط الموقع، مثلاً `https://smart-ats-khatab.netlify.app`
- **Redirect URLs**: أضف `https://smart-ats-khatab.netlify.app/**`

تسجيل الدخول بحساب موجود يعمل بدون هذه الخطوة. هي مؤجلة مع باقي إعدادات Supabase.

## ما الموجود داخل الحزمة

| الملف | دوره |
|---|---|
| `_headers` | ترويسات أمان: يمنع تشغيل أي سكربت من خارج الموقع، ويسمح بالاتصال بـ Supabase فقط، ويمنع عرض الموقع داخل مواقع أخرى، ويحفظ ملفات `assets` في المتصفح لأن أسماءها تتغير مع كل نسخة |
| `robots.txt` | يمنع محركات البحث من فهرسة التطبيق |
| `netlify.toml` (في المشروع) | يُستخدم فقط إذا ربطت Netlify بمستودع GitHub مستقبلاً، فيبني الموقع تلقائياً مع كل تعديل |

إذا نقلت قاعدة البيانات لنطاق خاص بدل `supabase.co`، أضف النطاق إلى `connect-src` في `public/_headers` (يوجد اختبار ينبهك إذا نسيت).

بديل: [Cloudflare Pages](https://pages.cloudflare.com) يقبل نفس الملف المضغوط بدون حد للتحميل، والخطوات مشابهة.
