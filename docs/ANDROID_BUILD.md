# تطبيق أندرويد

التطبيق نفسه (نفس كود الويب) داخل غلاف أندرويد (Capacitor). نسخة الويب تبقى تشتغل للابتوب والمتصفح.

## الحصول على التطبيق

كل تحديث على فرع `main` في GitHub يبني ملف APK تلقائياً (Actions ← Android APK، حوالي 3 دقائق) وينشره في **Releases** برقم الإصدار من `package.json` (مثلاً `v2.8.0`).

على الهاتف: افتح صفحة Releases في المستودع، نزّل `smart-ats.apk` وافتحه. أول مرة يطلب أندرويد السماح بتثبيت التطبيقات من هذا المصدر. التحديث: نزّل الإصدار الأحدث وثبّته فوق القديم، البيانات تبقى.

> النسخة الحالية موقّعة بمفتاح التطوير (debug)، تكفي للتجربة والتوزيع المباشر. للنشر على Google Play نحتاج مفتاح توقيع خاص (release) لاحقاً.

## إعداد مطلوب مرة واحدة في Supabase

روابط البريد (تأكيد الحساب، استعادة كلمة المرور، الدعوات) والرجوع من تسجيل الدخول بـ Google ترجع للتطبيق عبر العنوان `smartats://app`. لازم يكون مسموحاً:

Authentication ← URL Configuration ← **Redirect URLs** ← Add URL:

```
smartats://app**
```

بدونه: تسجيل الدخول بـ Google من التطبيق يرجع لصفحة الموقع بدل التطبيق، وروابط البريد تفتح الموقع.

## كيف يشتغل

| الموضوع | السلوك |
|---|---|
| زر الرجوع | يغلق النافذة أو اللوحة المفتوحة، ثم الشاشة الداخلية، ثم يرجع للرئيسية؛ من الرئيسية يخرج التطبيق للخلفية. شاشة إعدادات بها تغييرات غير محفوظة تسأل أولاً |
| تسجيل الدخول بـ Google | يفتح في متصفح الهاتف فوق التطبيق (Google يمنع تسجيل الدخول داخل التطبيقات)، ثم يرجع للتطبيق تلقائياً |
| روابط البريد | تفتح التطبيق مباشرة وتكمل العملية (تسجيل دخول، كلمة مرور جديدة، دعوة) |
| الشاشة | يرسم تحت شريط الحالة وشريط التنقل بدون أن يغطي المحتوى؛ يدعم الهاتف والتابلت بالوضعين |
| الرجوع من الخلفية | يقرأ حالة البورد فوراً |

كل ما يخص الغلاف في `src/platform/native.ts` فقط (يفرضه ESLint)، وكل شيء فيه لا يعمل شيئاً في المتصفح.

## بناء محلي (اختياري)

يحتاج Android Studio وJDK 21:

```bash
npm run android:sync   # يبني نسخة الويب (بدون source maps) وينسخها للمشروع
npm run android:open   # يفتح المشروع في Android Studio ← Build ← Build APK
```
