Smart ATS — Arabic email templates for Supabase
Paste each one in Supabase → Authentication → Emails → Templates.
Keep {{ .ConfirmationURL }} exactly as written.

==================================================================
1) Template: Magic Link   (invitations to an email that already has an account)
==================================================================
Subject:
دعوة إلى Smart ATS

Body (Message, HTML):
<div dir="rtl" style="font-family:Tahoma,Arial,sans-serif;font-size:15px;line-height:1.8;color:#0a1f3d">
  <h2 style="margin:0 0 12px">لديك دعوة إلى Smart ATS</h2>
  <p>دعاك أحد مسؤولي نظام Smart ATS للانضمام إلى جهازه.</p>
  <p>اضغط الزر على الهاتف المثبّت عليه التطبيق لتسجيل الدخول وعرض الدعوة وقبولها:</p>
  <p><a href="{{ .ConfirmationURL }}" style="display:inline-block;background:#0f2d57;color:#ffffff;padding:12px 22px;border-radius:12px;text-decoration:none;font-weight:bold">عرض الدعوة</a></p>
  <p style="color:#5b6b82;font-size:13px">يمكنك أيضاً تسجيل الدخول بحساب Google بنفس هذا البريد، وستظهر لك الدعوة مباشرة. الرابط صالح لمرة واحدة. إذا لم تكن تتوقع هذه الرسالة فتجاهلها.</p>
</div>

2) Template: Confirm signup
   (also sent when an invitation goes to an email without an account:
    Supabase makes the account and sends this email instead of Magic Link;
    the app adds invited_to / invited_by so it reads as an invitation)
==================================================================
Subject:
Smart ATS — تأكيد البريد الإلكتروني

Body (Message, HTML):
<div dir="rtl" style="font-family:Tahoma,Arial,sans-serif;font-size:15px;line-height:1.8;color:#0a1f3d">
{{ if .Data.invited_to }}
  <h2 style="margin:0 0 12px">لديك دعوة إلى Smart ATS</h2>
  <p>{{ if .Data.invited_by }}دعاك «{{ .Data.invited_by }}»{{ else }}دُعيت{{ end }} للوصول إلى نظام «{{ .Data.invited_to }}».</p>
  <p>اضغط الزر لتأكيد بريدك وفتح الدعوة في التطبيق، ثم عيّن كلمة مرور لحسابك.</p>
  <p><a href="{{ .ConfirmationURL }}" style="display:inline-block;background:#0f2d57;color:#ffffff;padding:12px 22px;border-radius:12px;text-decoration:none;font-weight:bold">فتح الدعوة</a></p>
{{ else }}
  <h2 style="margin:0 0 12px">أكّد بريدك الإلكتروني</h2>
  <p>اضغط الزر لتأكيد بريدك وإكمال إنشاء حسابك في Smart ATS.</p>
  <p><a href="{{ .ConfirmationURL }}" style="display:inline-block;background:#0f2d57;color:#ffffff;padding:12px 22px;border-radius:12px;text-decoration:none;font-weight:bold">تأكيد البريد</a></p>
{{ end }}
  <p style="color:#5b6b82;font-size:13px">افتح الرابط على الهاتف المثبّت عليه تطبيق Smart ATS. الرابط صالح لمرة واحدة. إذا لم تطلب ذلك فتجاهل هذه الرسالة.</p>
</div>
